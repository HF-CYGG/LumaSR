# LumaSR v0.3.2

## 新增

- 增加 GitHub Release 自动更新检查，应用进入前台时每 24 小时最多检查一次。
- 设置页增加自动检查开关和手动检查入口。
- 发现新版本时提供国内加速下载与 GitHub 原始下载两个入口。

## 发布与兼容性

- 更新元数据只读取 GitHub 公开 API，不使用自建服务器或 Gitee APK 分发。
- 下载地址从 Release 的 `browser_download_url` 动态获取，不再写死版本标签。
- 正式 APK 资产固定命名为 `LumaSR.apk`，并继续使用原有固定签名证书，支持覆盖升级。
- 最低支持 Android 10，正式 APK 仅包含 `arm64-v8a`。

## 校验

- 发布附件同时提供 `LumaSR.apk.sha256`。
- SHA-256 的实际值由发布构建脚本生成，以 GitHub Release 附件为准。
