# LumaSR v0.3.2

LumaSR v0.3.2 现已发布。本版本在继续保持图片本地处理、无需登录和无需自建更新服务器的基础上，新增应用内版本检查，并集中完善长任务可靠性、设备性能校准和超大图输出链路。

## 本次更新重点

### GitHub 自动更新检查

- 应用进入前台时进行机会式检查，每 24 小时最多自动请求一次，不启动常驻后台任务。
- 设置页新增“自动检查更新”开关和手动“检查更新”入口。
- 发现新版本后显示版本号与更新说明，并提供国内加速下载、GitHub 原始下载两个入口。
- 更新元数据只读取 GitHub 公共 Releases API，不使用自建服务器，也不依赖 Gitee 分发 APK。
- 下载地址直接采用 API 返回的 `browser_download_url`，不再根据版本号或文件名手工拼接。
- 兼容当前固定 `release` 标签：客户端从严格格式的 Release 标题识别真实版本，未来恢复 `v0.3.3` 等独立标签时也可继续识别。

### 性能与稳定性

- 增加本机性能校准、校准进度与诊断信息；只有校准证据满足要求时才启用优化路径，失败或不支持时保持保守回退。
- 完善 Vulkan/CPU 自适应调度、热状态暂停与恢复、前台长任务续跑和持久化任务交接。
- 优化 Extreme 超大图的分块、内存中间结果与流式 PNG 输出，降低峰值内存和重复拷贝风险。
- 加固任务取消、失败清理与最终文件发布，避免未完成输出被误识别为成功结果。

### 结果与使用体验

- 保持简洁的处理后结果预览，并支持保存 PNG 到系统媒体库和调用系统分享。
- 支持 Waifu2x、RealCUGAN、Real-ESRGAN 等内置模型工作流。
- 图片选择继续使用 Android Photo Picker / scoped storage；不申请不必要的广泛存储权限。

## 隐私说明

- 输入图片、模型推理与输出生成均在本机完成，不会上传到 LumaSR 服务器。
- 自动更新只向 GitHub 请求公开版本元数据。
- 选择“国内加速下载”时，第三方加速服务会接触该 APK 下载请求；如不希望使用第三方服务，请选择“GitHub 原始下载”。

## 下载与安装

1. 下载附件 `LumaSR-v0.3.2.apk`。
2. 如需校验完整性，同时下载 `LumaSR-v0.3.2.apk.sha256` 并核对 SHA-256。
3. 本包继续使用项目固定发布证书；已安装相同证书版本时可直接覆盖升级并保留应用数据。
4. 正式 APK 仅包含 `arm64-v8a`，建议在 Android 10 或更新版本上使用。

## 关于下载链接

本项目当前继续使用固定 GitHub 标签 `release`，因此附件地址形如：

```text
https://github.com/HF-CYGG/LumaSR/releases/download/release/LumaSR-v0.3.2.apk
```

URL 中的 `release` 不是版本号，这是预期行为；实际版本以 Release 标题 `LumaSR v0.3.2` 和 APK 内版本信息为准。国内加速地址是在上述完整 GitHub 地址前添加 `https://gh.jasonzeng.dev/`。

## 注意事项

- 不同设备、系统版本、GPU 驱动和温控状态下的处理速度会有差异；未经对应真机测试的机型不作性能承诺。
- 如果覆盖安装时提示签名冲突，请先确认安装包来源；卸载会清除应用内数据，请在操作前自行备份需要保留的内容。
- 模型与上游组件遵循各自许可，分发或二次打包前请确认对应授权要求。
