# LumaSR v0.3.3

LumaSR v0.3.3 是一次进度显示与发行兼容性修复版本，继续保持图片本地处理、无需登录和无需自建更新服务器。

## 本次更新

### 处理进度修复

- 修复实际处理期间进度长期停留在“准备中”，随后直接跳到完成的问题。
- 加载模型、分块推理和后续阶段的进度快照现在可以持续更新。
- 保持 tile 覆盖层、任务取消、批处理、重试和终态防回退语义不变。

### 更新与发行兼容性

- 支持从固定 `release` 标签的严格 Release 标题读取真实版本。
- 滚动发行 APK 使用版本化文件名，避免 CDN 或浏览器继续命中旧安装包。
- 加强 APK 文件名、版本、签名证书、ZIP 对齐、SHA-256 和发行清单校验。

## 下载与校验

1. 下载 `LumaSR-v0.3.3.apk`。
2. 使用同目录的 `LumaSR-v0.3.3.apk.sha256` 校验文件完整性。
3. `release-manifest.json` 同时记录版本、APK 文件名、SHA-256 和固定签名证书指纹。

正式 APK 仅包含 `arm64-v8a`，支持 Android 10 及以上版本。输入图片、模型推理与输出生成均在本机完成。

## 注意事项

- 不同设备、系统版本、GPU 驱动和温控状态下的处理速度会有差异。
- 如覆盖安装提示签名冲突，请先确认安装包来源；卸载应用会清除本地数据。
- 国内加速下载会由第三方加速服务处理 APK 请求；不希望使用第三方服务时请选择 GitHub 原始下载。
